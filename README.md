#### My Flet Extension
---
- **![flet-fonts](https://github.com/arief05652/flet-fonts)** lets you easily use many fonts provided by Google Fonts in your app
- **![flet-lucid](https://github.com/arief05652/flet-lucid)** allows you to use a rich collection of icons provided by Lucid
- **![expand-fab](https://github.com/arief05652/expand-fab)** is a multifunctional floating action button that is very useful for your Flet app
- **![flet-blurhash](https://github.com/arief05652/flet-blurhash)** allows you to create smooth blur effects for images
