#### My Flet Extension
---
- **flet-fonts** lets you easily use many fonts provided by Google Fonts in your app\
  ![PyPI - Version](https://img.shields.io/pypi/v/flet-fonts)
- **flet-lucid** allows you to use a rich collection of icons provided by Lucid\
  ![PyPI - Version](https://img.shields.io/pypi/v/flet-lucid)
- **expand-fab** is a multifunctional floating action button that is very useful for your Flet app\
  ![PyPI - Version](https://img.shields.io/pypi/v/expand-fab)
- **flet-blurhash** allows you to create smooth blur effects for images\
  ![PyPI - Version](https://img.shields.io/pypi/v/flet-blurhash)
